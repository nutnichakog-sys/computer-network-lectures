Application Layer

Deep Summary


Application Layer เป็น Layer ที่ให้บริการแก่ User Application

Concept สำคัญ:
- Client-Server และ P2P
- Socket = การสื่อสารระหว่าง Process
- IP Address + Port Number ใช้ระบุ Process

HTTP:
- Request / Response
- Stateless
- Cookie ใช้สร้าง State

TCP:
Reliable, ACK, Flow Control

UDP:
Fast, Connectionless

DNS:
Domain Name -> IP Address

Email:
SMTP ส่ง Email
IMAP/POP3 รับ Email

HTTP/2:
Multiplexing ลด HOL Blocking

HTTP/3:
QUIC over UDP

จำ Definition, Comparison และ Scenario
